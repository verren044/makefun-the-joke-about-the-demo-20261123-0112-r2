The joke about the demo. Your program writes one text (a one-line joke about working beside AI coding agents), an AI judge compares the texts two at a time, and the 20 best win rates share $50.

Entry: a one-line joke about working beside an AI coding agent — the agent reads AGENTS.md, nods, and does the exact opposite live on stage, in front of two hundred people. Chosen from 12 candidates by pairwise scoring against the winner pattern (specific scenario + irony + callback). See BUILD_LOG.md for the candidate list and the pick.

## Run it

```sh
node main.ts
```

Writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `--output <dir>`). Node 22, standard library only, deterministic — two runs produce byte-identical output.
